# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/) ([original en inglés](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)).

En corto: sé respetuoso, acepta las críticas con buena fe, céntrate en lo que es mejor para la comunidad y no toleramos el acoso ni los ataques personales de ningún tipo.

Para reportar una conducta inaceptable, contacta en privado con los mantenedores mediante un [aviso de seguridad privado](https://github.com/lanterndevv/lantern/security/advisories/new) del repositorio (o el contacto de su perfil de GitHub). Las quejas se tratan con confidencialidad.
