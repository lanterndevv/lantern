Respuestas reales de `character-service` (recortadas, sin usuario ni avatar) para validar `mapCharacter`.

- `rogue1-willie.json` — de [TeaWithLucas/DNDBeyond-DM-Screen](https://github.com/TeaWithLucas/DNDBeyond-DM-Screen) (`sample-character.json`), licencia MIT © sus autores. Versionado.
- El resto (`srsutherland/5ejson`, `MaximeBonnin/dnd-characters-dataset-24`, `andrewduckett/hero-slate`) procede de repos **sin licencia**: no se redistribuyen. Se usan solo en local; sus tests se saltan si no están. Para regenerarlos, descárgalos de esos repos o exporta personajes propios con `character-service.dndbeyond.com/character/v5/character/<id>`.
